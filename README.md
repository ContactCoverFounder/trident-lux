# Trident Lux Website

Static one-page website for Trident Lux Luxury Relocation & Concierge.

## How to put this on GitHub

1. Go to GitHub and create a new repository called `trident-lux`.
2. Upload these files:
   - `index.html`
   - `styles.css`
   - `vercel.json`
   - `README.md`
3. Connect the repository to Vercel.
4. In Vercel, select this GitHub repo and deploy.

## Recommended next edits

- Replace `hello@tridentlux.com` in `index.html` with your real email.
- Add your Calendly booking link to the consultation buttons.
- Replace placeholder service descriptions with your final Trident Lux packages.
- Add a real Port Vell sailboat image as the hero background if desired.
